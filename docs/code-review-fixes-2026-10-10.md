## 复审追加修复

- 文件监听器不再因归档移走文件而删除照片数据库记录；兼容恢复后的存储路径，防止重复注册。真实归档恢复确认原照片 ID、评论和照片总数保持不变。
- 标准 01_RAW / 02_PROOF 分目录项目撤回交付时，从 02_PROOF 恢复预览；不向 RAW 原目录写入 JPG。
- Bridge 有状态时，备份生成新的 PicPeak 数据库快照，避免复用旧快照造成两侧进度不一致；状态清单生成失败会判定备份失败。
- 修正手机多选下载与临时下载地址释放时机；鉴权和服务器错误不再伪装成资源缺失后继续回退下载。

## 客户手机端下载

手机多选后打开下载清单，每张照片由客户单独点击一次，保留原文件名和图片类型，不自动打包 ZIP。界面只提示已发起下载，不声称文件已经保存。微信环境提供在浏览器中打开的提示。

| 环境 | 测试范围 | 结果 |
|---|---|---|
| iPhone Safari | Playwright WebKit + iPhone 设备模拟：实际页面多选、逐张下载、文件名与文件内容 | 通过 |
| Android Chrome | Chromium + Pixel 设备模拟：实际页面多选、逐张下载、文件名与文件内容 | 通过 |
| 微信浏览器 | Chromium + 微信 User-Agent 模拟：下载清单与逐张下载 | 通过 |

以上不是物理手机测试。微信真实客户端的下载拦截、iOS 系统保存位置与实际设备权限仍需现场验收。

自动化入口：`playwright.downloads.config.ts` 与 `tests/mobile-downloads/downloads.spec.ts`；CI 在真实 PicPeak 测试容器启动并准备照片后执行。
