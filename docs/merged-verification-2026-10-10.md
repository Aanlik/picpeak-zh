## 审查问题闭环

| 问题 | 修复与验证 |
|---|---|
| 旧交付布局迁移后数据库路径未同步 | 持久化迁移记录，启动时重映射 RAW、历史与撤回路径；重启回归测试 |
| 撤回替换响应丢失 | 本地 outbox、Bridge 撤回任务与 operation ID；先核对标记，重启不重复上传 |
| 项目专属挂载导出路径错误 | 按项目映射宿主机与容器路径；多项目回归测试 |
| SELECTING 显示精修中 | 客户和后台根据阶段判断精修状态 |
| dev/main 汉化 CI 未覆盖 | 中文校验与统一 CI 覆盖 dev/main；发布依赖全部测试 |
| FINAL 每张照片重复遍历 | 每周期每版本缓存文件索引；50 张文件索引调用次数验证 |
| 审核分支与画布依赖残留 | 删除返修审核分支、迁移旧状态为 open，移除无引用前端依赖 |
| 替换新图前删除旧资源 | 先落新文件、条件更新数据库，提交后回收旧资源；存储/DB/并发故障测试 |
| 并行绑定产生重复配置 | 锁内再次检查项目和目录映射；并发 HTTP 绑定测试 |
| 阶段切换与同步竞争 | 阶段、恢复、版本目录与重试操作使用同一同步锁；归档等待测试 |
| 异常上传回执触发重复上传 | 无效 JSON/回执标记为 UNKNOWN；只核对，不盲目再传 |
| 定时刷新覆盖回复草稿 | 按需求保留本地草稿，防止异步旧项目响应覆盖新项目；定时器回归测试 |
| 离线归档恢复丢失 | 最新阶段意图写入数据库，后台定期恢复；离线与新意图覆盖测试 |
| 快照失败删除已有文件 | 只清理本次创建的目标；同名已有历史文件保留测试 |

撤回处理中，客户页面禁用重复选择，接口也拦截，后台显示待处理及具体错误。未知撤回的手动重试需要摄影师核对并明确确认。
