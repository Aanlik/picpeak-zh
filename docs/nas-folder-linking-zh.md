# NAS 文件夹直接关联

本次版本：PicPeak 3.134.1-zh.5；Bridge 保持 0.1.1。

已配置 Home/Camera → PicPeak 的只读照片入口 Camera；保留原验证项目挂载路径。真实拍摄目录不会自动导入任何项目，请在界面选择对应拍摄日期文件夹。

- 新建项目：在“关联 NAS 照片文件夹（可选）”展开 Camera，选择拍摄文件夹，创建后导入。
- 已有项目：进入“照片”，点击“关联 NAS 文件夹 / 重新扫描”，选择文件夹并关联。
- 勾选“自动导入此文件夹后续新增的照片”后，后台持续扫描新增照片；重复扫描会跳过已导入照片。
- 支持 JPG/JPEG/PNG/WebP，包括子文件夹。RAW 不展示给客户。
- 引用原文件，不重复上传；原文件不能移动、重命名或删除，否则已有引用无法读取。
- 新建项目时关联失败仍保留已创建项目，请到“照片”页继续，不要重复创建。
- 若照片已经导入但自动导入设置保存失败，会明确提示；重新扫描不会重复创建已导入照片。

网页可以浏览和关联管理员已挂载的目录，不能随意挂载整个 NAS。新增其他入口需由管理员在部署配置中添加只读挂载，再重新构建 Compose。

这次关联只负责客户相册照片入口。要自动生成待精修 RAW 和回传成片，仍需为对应项目配置独立 Bridge 的 RAW、SELECTED_RAW、FINAL、HISTORY 路径及 PicPeak 项目编号。

## 验证

自动化测试覆盖关联失败、自动导入设置失败、关闭自动导入；真实 PicPeak 容器验证 100 张照片导入、重复扫描去重、自动追加、原文件 SHA256 不变、只读写入拒绝、路径越界及符号链接拒绝。NAS 更新后检查既有 100 张照片编号、评论、分享链接和 Bridge 返修状态。
